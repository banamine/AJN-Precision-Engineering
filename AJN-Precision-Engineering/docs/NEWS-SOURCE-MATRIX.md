# Archive News Source Matrix

| Source | Archive collection | Callsign | Resolution |
|---|---|---|---|
| FOX News | `TV-FOXNEWSW` | `FOXNEWSW` | metadata -> real MP4 |
| CNN | `TV-CNNW` | `CNNW` | metadata -> real MP4 |
| MSNBC | `TV-MSNBCW` | `MSNBCW` | metadata -> real MP4 |
| BBC News | `TV-BBCNEWS` | `BBCNEWS` | metadata -> real MP4 |

Discovery is not playback verification.

A search result is only `DISCOVERED`.

An item becomes `PLAYABLE` only after its metadata contains an actual MP4 derivative.

No source-specific filename guessing is permitted.

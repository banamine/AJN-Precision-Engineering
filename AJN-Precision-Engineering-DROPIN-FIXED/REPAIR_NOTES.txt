Repairs:
1. App playback routing now resolves each source exactly once.
   - Already-proxied /api/archive/proxy URLs pass through unchanged.
   - /download/* Archive paths receive exactly one proxy wrapper.
   - absolute archive.org download URLs are canonicalized to the local proxy.
   - non-Archive HLS/DASH/MP4 sources remain direct.

2. Archive proxy now actually applies its MAX_CHUNK range policy.
   - Browser bytes=N- requests are converted to bounded upstream ranges.
   - response Content-Length/Content-Range come from the bounded upstream response.
   - malformed Range headers return 416.
   - nested proxy paths are rejected.
   - HTML/JSON/plain-text upstream responses are rejected instead of being sent to <video>.
   - CORS and proxy request ID headers are preserved.
   - client disconnect/upstream cancellation handling is retained.

This is a source drop-in. It does not intentionally alter navigation, EPG, Library, Search, or channel data.

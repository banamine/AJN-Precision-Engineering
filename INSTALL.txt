# AJN Archive Proxy Surgical Drop-In

Replace ONLY the existing `archiveProxy.ts` with the file in this ZIP.

Scope:
- Keeps the existing Archive path validation.
- Allows only `archive.org` and `ia<number>.us.archive.org` redirect targets.
- Resolves the Archive `/download/...` redirect server-side.
- Returns the validated storage-node URL to the browser with HTTP 302.
- Does NOT proxy the MP4 byte stream through Cloud Run.
- Does NOT modify channels, player, EPG, scheduler, or navigation.

Verification after deployment:

curl.exe -i -H "Range: bytes=0-1023" "https://ajn-precision-engineering.ai.studio/api/archive/proxy?path=%2Fdownload%2FFOXNEWSW_20260906_080000_My_View_With_Lara_Trump%2FFOXNEWSW_20260906_080000_My_View_With_Lara_Trump.mp4"

Expected:
HTTP/1.1 302 Found
Location: https://ia*.us.archive.org/...

Then:
curl.exe -L -i -H "Range: bytes=0-1023" "https://ajn-precision-engineering.ai.studio/api/archive/proxy?path=%2Fdownload%2FFOXNEWSW_20260906_080000_My_View_With_Lara_Trump%2FFOXNEWSW_20260906_080000_My_View_With_Lara_Trump.mp4"

Expected final response:
206 Partial Content
Content-Type: video/mp4
Accept-Ranges: bytes
Content-Range matching bytes 0-1023
Content-Length: 1024

This is a surgical transport change only.
